# SupportHub AI Ticket Taxonomy

## Purpose

This document defines the official ticket categories used throughout SupportHub AI.

The AI, backend, and UI must all use these categories.

| Category | Description | Example |
|----------|-------------|---------|
| account_access | Login, password reset, MFA, locked account | "I can't log in." |
| technical_issue | Bugs, crashes, unexpected behavior | "The app crashes when uploading." |
| billing | Payments, invoices, subscriptions, refunds | "I need a copy of my invoice." |
| product_question | Questions about features or usage | "Does the app support dark mode?" |
| security | Suspicious activity, compromised account, data concerns | "Someone logged into my account." |
| service_outage | Product unavailable for many users | "Our whole company can't access the platform." |
| other | Anything that does not fit another category | Miscellaneous requests |

## Rules

- Every ticket must belong to one category.
- Unknown tickets should be reviewed manually.
- Categories should remain consistent across the system.
